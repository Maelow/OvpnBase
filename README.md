# OvpnBase

Щорічне оновлення OpenVPN на MikroTik: новий клієнтський сертифікат, новий порт (паралельний сервер), профілі Windows/macOS, запаролені архіви.

## Запуск

`Start-OvpnBase.bat` — використовує PowerShell 7 (`pwsh`), якщо встановлено, інакше Windows PowerShell 5.1.
PowerShell 7 рекомендовано: тільки в ньому працює перевірка паскею приватного ключа.

## Вимоги до роутера

- RouterOS 7.17+ (кілька OVPN-серверів, `/file/read`), API 8728 доступний з ПК.
- Група API-користувача з політиками `api,read,write,test,ftp,sensitive`:

  ```
  /user group add name=ovpn-admin policy=api,read,write,test,ftp,sensitive
  /user set <api-user> group=ovpn-admin
  ```

## Порядок роботи

1. **Підключення** — адреса, логін, пароль API. Одразу перевіряються права групи; якщо чогось бракує — вікно зі списком політик і готовими командами (кнопка копіює їх).
2. **Діагностика** — OVPN-сервери, CA (trusted, key-usage, приватний ключ), серверний і клієнтські сертифікати, PPP-профіль/пул, локальні користувачі, RADIUS (лічильники), Zero Trust, DNS хоста, NTP, права API.
3. **CA і сервер** — стан кореневого CA (позначити trusted, backup CA з ключем на ПК) і **первинне налаштування** для роутера без OpenVPN: CA → серверний сертифікат → пул → PPP-профіль → сервер → порт лише через `MGMT_Allow` → RADIUS (опційно). Наявні об'єкти не змінюються.
4. **Параметри року** — рік, термін, сервер-джерело, новий порт, хости, маршрути, ключ, паскей, пароль архівів, перехідна дата.
5. **Користувачі** — режим автентифікації:
   - **RADIUS** (основний) — один спільний сертифікат, користувачі на роутері не створюються;
   - **Локальні користувачі** — для кожного `/ppp secret` (service=ovpn) + окремий сертифікат CN=логін + окремі архіви `out\<рік>\users\<логін>\`. Наявним — лише нові сертифікати; новим — secret з заданим або згенерованим паролем (показується в кінці, опційно `credentials.csv`).
6. **Виконання** — «Переглянути зміни» (dry-run) → «Виконати» (з підтвердженням).
7. **Обслуговування** — відкликання/видалення сертифікатів, увімкнення/вимкнення серверів, прибирання порту з правила, скасування переходу.

## Що змінюється на роутері

- `/export` → `out\<рік>\backup-*.rsc` (тимчасовий файл на роутері видаляється).
- `/certificate add` + `sign` (CA серверного сертифіката), експорт PEM з паскеєм (тимчасові файли видаляються).
- Якщо порт новий: `ovpn-server add copy-from=<поточний> port=<новий> disabled=yes` → порт додається **лише** в dst-port allow-правила з `src-address-list=MGMT_Allow` → перевірка Zero Trust (при помилці відкат) → увімкнення сервера. Старий сервер працює далі.
- Опційно scheduler `ovpn-cutover-<рік>`: у вказану дату вимикає старий сервер і прибирає його порт з правила.

Zero Trust портал (сервіс, що додає IP клієнтів у список доступу) не зачіпається.

## Результат (`out\<рік>\`)

| Файл | Для кого |
|---|---|
| `VPN-<рік>.exe` | Windows — 7z SFX, AES-256, приховані імена файлів |
| `VPN-<рік>-macOS-AES.zip` | macOS — AES-256 (Keka / The Unarchiver) |
| `VPN-<рік>-macOS.zip` | macOS — ZipCrypto (стандартний Archive Utility, слабкий захист) |
| `profiles\*.ovpn` | незашифровані копії (можна видаляти автоматично) |
| `report.txt`, `backup-*.rsc` | звіт і backup конфігу |

В архівах за замовчуванням лише `.ovpn`. Інструкцію `README-Windows/macOS.txt` (з адресою Zero Trust порталу) можна увімкнути галочкою в картці «Профіль».

Паролі не зберігаються (`settings.json` містить лише несекретні налаштування), у журналі (`logs\`) маскуються.

## Тести

- `tests\Run-Diagnostics.ps1` — консольна діагностика (тільки читання).
- `tests\Test-Offline.ps1 [-Router … -User … -Password …]` — локальна перевірка сертифікатів/профілів/архівів + dry-run план.
- `tests\Test-RouterCertCycle.ps1` — створює тимчасовий 1-денний сертифікат, підписує, експортує, перевіряє і видаляє.

## Налаштування і поширення

- `sample-settings.json` — шаблон без IP-адрес, доменів і логінів. Якщо `settings.json` відсутній, при першому запуску він створюється копією шаблону.
- `settings.json` — ваші локальні налаштування (адреса роутера, логін API, хости, маршрути). Паролів у ньому немає.
- Якщо хост і маршрути порожні, вони підтягуються з профілю попереднього року в `sample\*.ovpn` (якщо такий є).

Щоб поділитися скриптом, передавайте: `OvpnBase.ps1`, `Start-OvpnBase.bat`, `sample-settings.json`, `README.md`, `lib\`, `tests\`, `tools\7z\`.
**Не передавайте:** `settings.json`, `sample\` (там реальний профіль з ключем), `out\` (сертифікати, архіви, backup CA і конфігу), `logs\`.
